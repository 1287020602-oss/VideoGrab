VideoGrab 2.3.2 媒体下载工具
=============================

启动方式
--------
双击“Start VideoGrab.cmd”即可打开。

基本使用
--------
1. 在“下载”页面粘贴视频页面链接或媒体直链。
2. 选择需要保存的内容：视频、封面、MP3；可以同时选择多项。
3. 选择视频画质和保存位置。
4. 可先点击“解析”查看标题、来源、时长与可用格式，也可以直接点击“下载所选内容”。
5. 下载完成后，可在“历史记录”中打开保存位置。

中英文切换
----------
1. 打开左侧“设置”。
2. 在第一项“界面语言”中选择“中文”或“English”。
3. 界面会立即切换，选择会自动保存，下次启动继续使用。

字号调整
--------
1. 打开左侧“设置”。
2. 在“界面字号”中选择：小 90%、标准 100%、大 115% 或特大 130%。
3. 字号会立即应用到整个程序并自动保存。
4. Windows 使用微软雅黑 UI，macOS 使用苹方 PingFang SC。

需要登录的视频
--------------
1. 打开左侧“浏览器”。
2. 选择已经登录对应网站的 Microsoft Edge 或 Google Chrome。
3. 建议先关闭所选浏览器，再回到“下载”页面解析链接。
4. 浏览器数据只在本机读取，不会上传到 VideoGrab。

设置
----
- 默认下载文件夹
- 默认视频画质（最佳、4K、2K、1080p、720p、480p）
- 文件命名方式
- 浏览器登录状态来源
- 网络代理地址（例如 http://127.0.0.1:7897）
- 下载完成后是否自动打开文件夹
- 是否保留本机下载历史
- 中文 / English 界面切换
- 小、标准、大、特大四档界面字号
- 统一的 24px 圆角描边图标系统

支持范围
--------
- 支持 yt-dlp 能识别的常见公开视频站点，包括 YouTube、B站、TikTok、Instagram 等。
- 也支持部分普通网页中的媒体链接或视频直链。
- 网站规则会变化；若某个链接突然失效，通常需要更新 yt-dlp。
- 不支持绕过 DRM、付费限制、验证码、私密权限或平台访问控制。
- 请只下载你拥有版权或已经获得许可保存的内容。

默认保存位置
------------
当前 Windows 用户的 Downloads\VideoGrab 文件夹。
手机配对
--------
点击左侧品牌区副标题右侧的手机角标，即可在客户端内调出二维码。
电脑和 iPhone 需连接同一个 Wi-Fi；关闭 VideoGrab 主客户端会断开手机连接。

公开网页

点击手机角标旁的地球角标，可生成临时公网地址和二维码，任何人用浏览器打开即可使用。
公开网页仅在电脑开机且 VideoGrab 运行时有效；重新开启时地址会变化。
公开模式不读取本机浏览器登录状态，文件保留 2 小时，并限制每位访客的请求频率。

2.3.1 更新

- 更新 yt-dlp 至 2026.08.19，修复近期 YouTube 解析及 HTTP 403 下载失败。
- 保留 Node.js JavaScript 挑战处理能力，并通过公开视频实际下载验证。

2.3.2 更新

- 新增“设置 → 网络代理”。若当前网络被 YouTube 要求人机验证，可填入正在运行的代理地址后重新解析。
- 将此代理用于客户端和配套网页端的解析、下载请求。
- 人机验证错误会显示更明确的中文处理提示。
